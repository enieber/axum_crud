# Axum CRUD

Create crud with axum and shared state with arc and mutex.

## Development

Install dependencies and compile:

`cargo build`

Run in development:

`cargo run`

## Test

To run tests is use hurl.dev:

`hurl --variable host=http://localhost:3000 tests/tasks.hurl`
